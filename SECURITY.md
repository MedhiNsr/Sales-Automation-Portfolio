# Security and Privacy

Sales Automation can process commercially sensitive and personal information including prospect identities, business email addresses, campaign copy, attachments, reply history and internal account-management decisions.

## Public repository boundary
The portfolio repository must not contain real prospect lists, live email addresses, client lists, internal campaign copy, live attachments, Outlook credentials, operational databases, message history, logs, backups, absolute local-machine paths or company-confidential configuration.

Portfolio examples should use synthetic companies, contacts and addresses. Configuration examples must use placeholders only.

The operational system remains separate from this repository. The public-facing version is intended to demonstrate workflow architecture and product decisions without exposing commercial data.
